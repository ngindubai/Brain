## Story 1: Google's Smart Bidding change is live today — correcting yesterday's timeline

**Source:** Digital Autopilot | https://www.digitalautopilot.com.au/google-ads-bidding-change-august-2026/ ; corroborated by Search Engine Journal and Avocado TS coverage of the same 17 August effective date

**Related vault notes:** [[SEO Portfolio]], [[Comparison Network]], [[Priorities]]

Correction to yesterday's open loop: this change is effective **today, Monday 17 August**, not tomorrow. Multiple independent sources confirm the date — Google itself set 17 August as the cutover, and yesterday's "Tuesday 18 August" framing was wrong. If nothing was actioned over the weekend on this assumption, it needs checking today, not tomorrow morning.

What changes: for any campaign flagged "Limited by budget" in Google Ads and running a target-based bid strategy (Target CPA, Target ROAS, or Target CPC for Demand Gen), Smart Bidding stops quietly over-delivering against the stated target. A campaign with a $10 Target CPA that's actually been running at $5 will now be pushed to deliver closer to the real $10 target, including when budget is increased. The change spans Search, Shopping, Performance Max, Demand Gen, and Travel campaigns. Campaigns on Manual CPC or Maximise strategies, or that aren't budget-limited, are untouched.

Google's own framing is that this makes performance "more predictable" — the honest translation is that any campaign that's been coasting on an unrealistic target is about to get more expensive per conversion, because the algorithm will stop quietly compensating for a target nobody bothered to correct. Google's recommended playbook, gathered from today's coverage, is one of five moves: accept the drift, lower the target to match real performance, split the difference, switch to a Maximise strategy, or ramp the target up gradually. A Bid Target Adjustment Tool has been live in-platform since 6 July specifically to make this audit easier.

For the portfolio, this lands squarely on top of the live LSA-to-Performance-Max migration on pest-control-usa (phase 1, first wave already running) — any PMax campaign there that's budget-limited and coasting on a soft target is now exposed to a cost jump today. The comparison network sites running Search or PMax lead-gen campaigns (mortgagecompare-ae, moneycompare-ae, insurecompare-ae in particular, given UAE finance CPCs) should get a same-day check of the "Limited by budget" status column before assuming yesterday's numbers still hold tomorrow.

**Action:** audit every Target CPA/ROAS campaign across the portfolio and comparison network for "Limited by budget" status today, not later this week.

## Story 2: ChatGPT Ads switches on Automatic Advanced Matching for existing pixels today

**Source:** PPC Land | https://ppc.land/chatgpt-advertisers-face-10-days-to-opt-out-of-automatic-advanced-matching/ ; corroborated by Cittago and The State of AI Marketing coverage of the 17 August effective date

**Related vault notes:** [[SEO Portfolio]], [[Comparison Network]], [[Agent Org]]

OpenAI's Automatic Advanced Matching (AAM) becomes the default for all existing ChatGPT Ads web pixels today. AAM has been the default for newly created pixels for a while; from today it back-applies to pixels that were already live. Mechanically, the ChatGPT Ads pixel reads customer information typed into on-site forms (email, phone, name), hashes it client-side, and sends the hash alongside the conversion event so OpenAI can match more conversions back to ad interactions it can't otherwise see. Advertisers who don't want this had a window to opt out via Tools → Conversions → Data Source → Edit pixel; that window closed as of today.

This is a small mechanical change but it's a marker of something bigger: OpenAI is now running its ads stack with the same conversion-matching playbook Meta and Google built over the last decade, and it dropped nine separate product changes to advertisers in the space of two weeks (the week of 3 August email, expansion to Brazil and Mexico, oCPC beta, and now this). Any part of the portfolio experimenting with ChatGPT Ads — most plausibly the comparison network testing AI-search-adjacent placements, or KlientFlo-type client work touching paid GEO — should check pixel settings today if data-sharing exposure via hashed PII matters for the account.

This is a small story on its own, but it's the second piece of evidence in a week (alongside yesterday's open loop items) that OpenAI's ads product is maturing fast enough to need the same governance attention as Google Ads and Meta.
