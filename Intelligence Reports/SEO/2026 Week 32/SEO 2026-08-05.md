## Story 1: Google Ads API passkey mandate takes effect today

**Source:** PPC Land | https://ppc.land/google-ads-will-require-passkeys-for-sensitive-actions-from-july-15/ ; Search Engine Land | https://searchengineland.com/google-makes-passkeys-mandatory-for-google-ads-api-users-483617

As of today, 5 August, Google requires passkey authentication for anyone generating new OAuth 2.0 refresh tokens on the Google Ads API. Password-only sign-in no longer works for that flow, and neither do TOTP authenticator apps or SMS-based two-factor codes, passkeys only. The rollout reaches all users over the following weeks. Existing, already-live OAuth tokens keep working with no reauthorisation prompt, and service accounts are exempt, so this only bites when someone needs to generate a brand-new API connection. Google's own warning is the sharpest detail: a newly created passkey can take up to 7 days before it's trusted for this workflow, so enrolling one the morning it's needed may not be enough. Announced on the Google Ads Developer Blog on 27 July.

**Signal for Orwell:** Directly relevant. Any tool or script touching [[Comparison Network]] or portfolio-site Google Ads accounts via the API, reporting dashboards, bulk campaign management, anything scripted, needs a passkey enrolled and trusted before the next time a fresh API connection is needed, not on the day it's needed. Worth a five-minute check of whatever's currently connected via API.

## Story 2: Multiple rank trackers confirm SERP volatility spanning 1-3 August, cause unconfirmed

**Source:** Substituted via WebSearch (Search Engine Roundtable blocked) — corroborated across multiple secondary sources reporting the same underlying SE Roundtable post, https://www.seroundtable.com/google-search-ranking-volatility-august-1-41811.html

Ten separate third-party rank-tracking tools, AccuRanker, Algoroo, Mozcast, Semrush Sensor, Serpstat, SimilarWeb, Sistrix, Wincher, Wireboard and Zutrix, all recorded a volatility spike beginning Saturday 1 August and running through 3 August. SEO community reports describe mixed outcomes (some sites gaining, others losing) with unusually heavy reshuffling favouring YouTube video results in some verticals. No named Google update, core, spam or otherwise, has been confirmed as the cause, and the timing lines up with a pattern of unexplained volatility on the 1st of June, July and now August.

This closes out a loop this report has carried as "unreadable" for several days running: the Sensor dashboard itself may still be unreachable by any tool available here, but enough independent trackers now agree a real event happened that it's safe to treat as confirmed, even without Google's own acknowledgement. The monthly-first-of-month pattern (June, July, August) is worth watching; three in a row starts to look less like coincidence.

**Signal for Orwell:** Worth a quick Search Console glance on any [[SEO Portfolio]] or [[Comparison Network]] property for unusual ranking movement 1-3 August specifically. No action beyond that until a pattern or named update emerges.

## Story 3: Bing Webmaster Tools retires SOAP/POX APIs 31 August

**Source:** Substituted via WebSearch (no single primary source with full detail surfaced; referenced across multiple SEO news aggregators)

Microsoft is retiring the legacy SOAP/POX version of the Bing Webmaster Tools API on 31 August 2026, pushing all remaining integrations onto the JSON/HTTP (REST) version. This is a housekeeping deadline rather than a strategy shift, but it will break any script or tool still calling the old endpoint format after the cutoff.

**Signal for Orwell:** Low urgency, but worth a check if anything in the [[SEO Portfolio]] or [[Comparison Network]] toolchain still submits sitemaps or pulls Bing data via the older API format. Most modern SEO tools have already migrated; this is really only a risk for custom scripts.
