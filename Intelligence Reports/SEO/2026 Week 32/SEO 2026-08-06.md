## Story 1: AdSense "Related Search" Auto ads format retires today

**Source:** PPC Land | https://ppc.land/google-kills-adsense-related-search-format-for-auto-ads-on-august-6/ ; Google AdSense Help | https://support.google.com/adsense/answer/12999250

**Related vault notes:** [[SEO Portfolio]], [[Comparison Network]]

As flagged in yesterday's open loops, this happened today as scheduled. The "Related search" format inside Google AdSense Auto ads is retired from 6 August 2026 — the live ad unit stops serving and the control disappears from the AdSense interface entirely. Google has been notifying publishers by email over the past few weeks; no action is required, and other Auto ads formats continue operating normally. This is the latest in a roughly 18-month contraction of AdSense's search-adjacent ad products.

For any site running Auto ads with Related Search enabled, today's impression and RPM numbers will show a step-change that has nothing to do with rankings or traffic — it's the unit disappearing. Worth ruling out before chasing a phantom algorithm problem.

**Signal for Orwell:** If any SEO portfolio or comparison-network property runs AdSense Auto ads, check today's RPM against yesterday's before assuming a ranking issue — a dip is most likely this retirement, not the algorithm.

## Story 2: Local Services Ads to Performance Max migration — phase 1 confirmed live this month, pest control named

**Source:** Google Ads Help | https://support.google.com/google-ads/answer/17213585 ; Shopifreaks | https://www.shopifreaks.com/google-retires-standalone-local-services-ads-dashboard-moving-pay-per-lead-campaigns-into-performance-max-starting-august-2026/

**Related vault notes:** [[SEO Portfolio]]

Update to the open loop from yesterday, which had no confirmed date. There's still no day-of-month, but Google Ads Help now confirms phase 1 has begun this month: US home and storefront service categories — plumbing, HVAC, electrical, house cleaning, roofing, and **pest control**, named explicitly — migrate first, with service-area businesses and custom-bidding accounts following in late 2026, and non-US accounts in 2027. Pay-per-lead pricing and keywordless, Google Business Profile-driven targeting carry over into Performance Max, but the standalone LSA dashboard ceases to exist the moment each account's individual migration lands.

Because the trigger is per-account rather than a single flag day, pest-control-usa's LSA account could move with no more warning than an in-product notice.

**Signal for Orwell:** Pull and archive pest-control-usa's LSA-only dashboard reports now, before the account migrates and that view disappears.

## Story 5: FAQ rich results Search Console API deprecation window is now open

**Source:** Google Search Central deprecation notice, via web search corroboration across Search Engine Journal, TechWyse, and others

**Related vault notes:** [[SEO Portfolio]], [[Comparison Network]]

We're now inside the announced removal month for the final stage of Google's FAQ rich results deprecation: FAQ rich results stopped appearing in Search on 7 May 2026, the Search Console UI report and Rich Results Test support were removed in June, and Search Console API support for FAQ rich result data is scheduled to go in "August 2026" — no specific day has been published, and none turned up in today's check either. Anything reading FAQ rich result stats via the Search Console API (custom dashboards, reporting scripts) could break with no more warning than the month itself.

**Signal for Orwell:** If any portfolio or comparison-network reporting pulls FAQ rich result data programmatically, check it now rather than after it silently stops returning data — no exact date to plan around, so treat any day from here as live.
