## Story 1: Google redesigns commercial search results across the EEA

**Source:** Search Engine Journal, 12 September 2026 (documented by Google Search Central, 8 September) | https://www.searchenginejournal.com/google-search-redesign-business-profile-post-views-seo-pulse/589151/
**Related vault notes:** [[Comparison Network]]

Google has rolled out new commercial result layouts across the European Economic Area, introducing two new unit types: comparison-site units, where the top-ranked provider now appears expanded by default and requires a feed or API integration to populate, and direct-supplier units, which sit alongside aggregator units without needing extra data work. This is the regulatory-driven Search redesign Google has been iterating on since its EU compliance changes earlier in the year.

The practical risk is measurement, not ranking: regional rank trackers and Search Console data for EEA queries may now diverge from other markets purely because of layout changes, not because visibility actually moved. Anyone reading UAE or EU-adjacent performance data at face value this week should sanity-check whether a drop is a real ranking loss or a template artefact. Directly relevant to [[Comparison Network]] — mortgagecompare-ae, moneycompare-ae, insurecompare-ae and companyformation.ae all run comparison-style result formats, and if this layout logic extends beyond the EEA it changes how those sites need to structure feeds to win the expanded unit. Worth a Semrush position-tracking check on the network's EU-facing pages if any exist, and a watch-item for whether Google extends this outside the EEA.

## Story 2: Google Business Profile post view counts return after 3.5-year gap

**Source:** Search Engine Journal, 12 September 2026, citing Google's September Small Business Bulletin | https://www.searchenginejournal.com/google-search-redesign-business-profile-post-views-seo-pulse/589151/
**Related vault notes:** [[SEO Portfolio]]

Google has reinstated view counts on Business Profile posts, which it removed on 20 February 2023. Counts now show on each post card in the dashboard, cover a rolling 18-month window, and combine views from both Search and Maps. The data is not yet exposed via the API, so it is dashboard-only for now.

This is a genuinely useful local-SEO signal after a long blackout, but it's shallow: views only, no clicks, no conversion signal, no way to attribute to a specific keyword or query. For any Orwell entity running local-service pages (close protection, pest control, bus hire all have local/regional angles) this restores a basic feedback loop on whether Business Profile posting is worth the agent time, but it shouldn't be over-read as a ranking or lead-quality metric. Relevant to [[SEO Portfolio]] for any local-intent pages in that stable.

## Story 3: ChatGPT Shopping increasingly gated behind product feeds, not organic content

**Source:** Search Engine Journal, 12 September 2026, citing Profound data (1,757,723 tracked prompt runs, July 2026) | https://www.searchenginejournal.com/google-search-redesign-business-profile-post-views-seo-pulse/589151/
**Related vault notes:** [[Agent Org]]

Profound's data shows the share of ChatGPT Shopping recommendations sourced from integrated product feeds jumped from 8.26% to 61.54% by 10 July 2026. Of 687 tracked customers, 450 saw at least a one-third drop in ChatGPT Shopping visibility over the period — a direct consequence of OpenAI shifting toward structured feed ingestion rather than crawling and ranking merchant content organically.

This is a GEO-relevant structural shift: for any ecommerce-adjacent property in the portfolio, visibility inside ChatGPT Shopping is becoming a feed-integration problem (Merchant Center-style structured data) rather than a content-quality problem. It mirrors the same pattern already seen in Google's AI Shopping surfaces. Worth a line in [[Agent Org]] design notes if any future venture touches product listings — feed plumbing now matters more than page copy for that specific channel.

## Story 4: Google quietly documents a partner-only "Web Search Service" API

**Source:** Search Engine Journal, 11 September 2026, citing Google developer documentation updated 9 September 2026 | https://www.searchenginejournal.com/google-documents-partner-only-api-for-full-web-search-results/589194/
**Related vault notes:** [[SEO Portfolio]]

Google refreshed its developer documentation (overview page plus four reference pages) for a "Web Search Service API" that returns full Google Search results in JSON via REST or gRPC — up to 20 results per request, filterable by language, country, date range and SafeSearch, with title, URL, snippet, MIME type and estimated result count in the response. No announcement accompanied the change.

The gate is a partner agreement tied to the API client ID — this is not something a developer can self-enable in Google Cloud. Google said in January 2026 that Custom Search JSON API users needing full-web results should "contact them," and this appears to be the mechanism, but the documentation still does not explain how to become a partner, at what cost, or under what query limits. The Custom Search JSON API sunsets 1 January 2027, so anyone in the portfolio using it for structured Google result data (rank-checking tooling, comparison-network feed logic) is on a clock with no published replacement path yet. Flagging as a new open loop rather than a resolved one.

## Story 5: University of Washington study quantifies AI Overviews' hit to Wikipedia referrals

**Source:** Search Engine Journal, 11 September 2026, citing a working paper by Mehrzad Khosravi and Hema Yoganarasimhan (University of Washington) | https://www.searchenginejournal.com/what-wikipedia-reveals-about-ai-overviews-and-web-traffic/589042/
**Related vault notes:** [[SEO Portfolio]]

Using English Wikipedia as the treatment group and German/French editions (no default AI Overviews) as controls, across roughly 500,000 matched article pairs from December 2023 to December 2024, the study finds AI Overviews cut monthly search referrals to English Wikipedia by about 5% after the May 2024 US default rollout — roughly 100 million fewer monthly referrals, ~1.2 billion annually. Wikimedia separately reports an 8% overall drop in human pageviews across all languages, blamed on generative AI and social competition, alongside a sharp rise in AI-training bot traffic (now over 65% of bandwidth-heavy Wikipedia traffic).

The study is a year-old dataset published now, and it measures direct search referral loss specifically — it can't isolate Google from other search engines, and it says nothing about commercial or transactional queries. But it's the cleanest causal estimate to date of AI Overviews' organic traffic tax, and the informational-content pattern (5% baseline referral loss, worse for high-authority reference content that AI Overviews can summarise cleanly) is the same shape of risk facing informational pages across [[SEO Portfolio]] — pet transport, funeral repatriation and pest control all carry informational/guide content that is exactly the kind AI Overviews cannibalises hardest. No new mitigation here, just a harder number behind the existing threat.

## Story 6: Ahrefs changes API traffic defaults, sets 30 September deadline for AI-adjusted volume

**Source:** Ahrefs API changelog / developer documentation, via web search (RSS feed 404'd) | https://ahrefs.com/blog/new-features/ and https://releasebot.io/updates/ahrefs/ahrefs-api
**Related vault notes:** [[SEO Portfolio]]

Ahrefs has changed the default `traffic_mode` on Site Explorer API endpoints from `static` to `adaptive` — anyone with automated Ahrefs pulls needs to explicitly pass `traffic_mode=static` to keep the old organic traffic calculation, or their historical comparisons will silently shift baseline. Separately, Ahrefs is retiring plain keyword volume on Brand Radar endpoints as of 30 September 2026, after which all requests return AI-adjusted volume only. Ahrefs also added an AI Discoverability issue category to Site Audit's Project Issues endpoint and a Content Helper Topics endpoint for scoring a target URL against competitor topic coverage.

Any dashboard or reporting pipeline pulling Ahrefs data programmatically for the portfolio needs a check before 30 September or volume figures will move without any real change in search demand. This is a genuine action item, not just a note — worth checking whether anything in the Orwell stack calls the Ahrefs API directly.
