## Story 1: GitHub trending shows continued momentum for agent-native tooling and edge models

**Source:** GitHub Trending | https://github.com/trending

**Related vault notes:** [[Agent Org]], [[Products]]

Today's trending list is led by **unsloth** (72.1k stars, +434 today), a local UI for running and training open models including Qwen3.8, Kimi K3, MiniMax-H3, Gemma 4 and DeepSeek-V4. Just behind it, **CLI-Anything** (47.4k stars, +118 today) is pitched squarely at making existing software "agent-native" via a CLI hub for agentic workflows, and **ego-lite** (11k stars, +545 today, the day's fastest mover) is a browser built specifically for AI agents to run browser automation, sharing logged-in browser state with agents like Claude Code without disturbing the human user. **cactus-compute/needle**, a 14MB foundation model built for tiny devices — phones, wearables, smart-home hardware, robots — also gained ground (+547 stars today).

This is a snapshot, not a launch announcement — none of these are today-dated releases — but the pattern across the four fastest-moving repos is consistent: tooling that makes agents operate directly inside existing software and hardware (CLI-Anything, ego-lite) is pulling ahead of tooling that just runs bigger models locally (unsloth, needle). Browser automation with shared session state in particular is a capability gap Orwell's own agent roles regularly hit.

**Signal for Orwell:** No action item, but ego-lite is worth a closer look if any [[Agent Org]] role needs browser automation that reuses a logged-in human session rather than authenticating fresh — that's a real capability gap in the current stack.
