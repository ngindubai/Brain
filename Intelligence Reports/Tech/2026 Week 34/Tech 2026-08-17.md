## Story 1: Google shuts down the Imagen 4 API, pushes everyone to Gemini image models

**Source:** Google AI for Developers (changelog) + kingy.ai / byteiota (deprecation trackers) | https://ai.google.dev/gemini-api/docs/changelog

Google's `imagen-4.0-generate-001`, `imagen-4.0-fast-generate-001` and `imagen-4.0-ultra-generate-001` endpoints go dark today. Google flagged the deprecation back in June; today is the hard cutoff. Anything still calling those endpoints via `generate_images()` breaks, full stop — the method itself is gone, not just the model. The recommended migration path is `gemini-3.1-flash-image` ("Nano Banana") through `generate_content()`, which is a different call shape, not a drop-in swap.

This is a small story but a real one for anyone with programmatic image generation wired into a pipeline — the kind of thing that fails silently until a script errors out. Google is consolidating image generation fully under the Gemini family rather than running Imagen as a parallel product line, which is worth noting as a pattern: expect the same treatment for Veo endpoints on a similar timeline (Google has already deprecated some Veo models in the same changelog).

**Why it matters for Orwell:** if any SEO portfolio site, comparison network asset, or client build calls Imagen 4 directly for thumbnails, hero images or programmatic content assets, that call is broken as of today. Worth a five-minute grep across the repos for `imagen-4.0` references before assuming nothing's affected.

## Story 3: Today's arXiv batch is unusually agent-governance heavy

**Source:** arXiv cs.MA listing (with cs.AI cross-listings) | https://arxiv.org/list/cs.MA/recent

Monday's arXiv drop (dated 17 Aug 2026) skews hard toward controlling and stabilising autonomous agents rather than making them smarter. The standout is "Agentao: A Governed Local-First Runtime for Tool-Using LLM Agents" (Jin, Jiao, Tong) — a runtime that keeps agent execution local-first with built-in governance hooks, rather than routing every tool call through a centrally-hosted control plane. Alongside it: "A Graph-Based Reinforcement Learning Framework for Structured Drift Diagnosis and Recovery in Autonomous LLM Agents" (El Hamraoui et al.), which tackles the unglamorous but real problem of agents drifting off-task over long runs and how to detect and recover from it automatically, and "MobileMem: Learning from a Year of Mobile Experiences" (Deng, Xue, Ru et al.), which looks at long-horizon memory built from a full year of on-device agent interaction rather than a single session.

None of these are framework launches — they're research papers, not shipping products — but the cluster is a useful read on where the field's attention is: governed execution, drift detection, and durable memory are exactly the gaps that show up once you run agents unattended for real work rather than in a demo. That's the same territory [[Agent Org]] design decisions live in.
